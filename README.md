# sistema-de-gestao-de-biblioteca
O sistema usa a **Classe** `Livro` como molde para criar **Objetos** com título e autor. Eles ficam guardados em uma **Lista** (o acervo). Através de **Funções**, o código altera o estado do livro de "disponível" para "emprestado". Um **Laço** de repetição mantém o menu funcional no terminal.
